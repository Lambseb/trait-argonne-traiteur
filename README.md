# Trait Argonne Traiteur – site vitrine
Site statique : ouvrir `index.html` dans un navigateur.

- `index.html`, `prestations.html`, `galerie.html`, `a-propos.html`, `contact.html`, `menus.html` + pages légales
- `prestations/` : une page par prestation
- `assets/css/` : `base` (variables, reset) · `layout` (structure) · `components` (boutons, cartes, carrousel) · `pages` (formulaire)
- `assets/js/` : `nav` (menu mobile) · `carousel` (défilement auto) · `reveal` (apparition progressive) · `devis-form` (formulaire)
- `assets/img/` : photos

## SEO (à compléter avant la mise en ligne)
Remplacer partout `https://www.trait-argonne-traiteur.fr` par le vrai domaine (HTML, `sitemap.xml`, `robots.txt`, `llms.txt`), puis compléter téléphone, email et adresse dans le JSON-LD de `index.html`.
